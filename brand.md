## Typography — SF Pro (system)

- **UI:** `-apple-system`, `BlinkMacSystemFont`, `"SF Pro Text"`, `"SF Pro Display"`, `system-ui`
- **Numbers / mono:** `ui-monospace`, `"SF Mono"`, `Menlo`

No web font load — matches native macOS/iOS apps. Windows/Android fall back to system UI.

## Tone & voice

**Personality:** Quiet confidence. MyTicker feels like a native Apple utility: dense information, no visual noise, gold only where it earns attention.

**Do:** Short labels, tabular numbers, uppercase section headers with wide letter-spacing, generous corner radius (12px).

**Don't:** Neon accents, heavy glows, gradient overload, or playful meme styling — premium restraint over degen energy.

## Usage

- Import `brand.css` in any new UI surface before page-specific styles.
- Ticker strip uses matching fallbacks in `ticker.css` (`--pts-*` vars).
- P&L colors stay semantic green/red; brand gold is for chrome and focus only.
