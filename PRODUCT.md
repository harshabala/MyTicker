# Product

## Register

product

## Users
Stock and crypto retail investors who want to monitor their holdings and real-time P&L (5-minute and daily window) seamlessly while browsing, without constantly checking separate broker tabs or apps.

## Product Purpose
A local-first browser extension (Chrome MV3) that projects a subtle ticker strip of holdings and real-time profit/loss across all tabs, offering a quick-toggle popup and an Apple-minimal configuration settings page with multi-broker CSV imports.

## Brand Personality
- Minimalist
- Obsidian Gold (rare accent)
- High-utility
- Precise ambient companion

## Anti-references
- AI-purple gradient glows and blue grid meshes
- Centered layout hero blocks in settings or popup
- Tiny uppercase tracked kicker eyebrows above every section
- Identical card grids with generic illustrations
- Gold section titles / multi-stop chrome gradients / TV-news marquee energy
- Fintech “hero metric” billboard cosplay

## Design Principles
1. **Utmost Restraint**: The ticker strip is an ambient background companion. Spacing, typography, and colors must remain quiet so they never distract from page content.
2. **Apple-style Materiality**: Use subtle dark-tinted backgrounds, thin borders, and crisp high-contrast text. No soft floating drop shadows on dark components.
3. **Data-density Efficiency**: Group related configuration elements clearly. Prefer list rows and progressive disclosure over stacked card rooms.
4. **Gold is rare metal**: CTAs and focus only — never section wallpaper.
5. **Money first**: Popup hierarchy is P&L → meta → optional detail.

## Accessibility & Inclusion
- Target WCAG AA color contrast (≥4.5:1 for body and data labels).
- Support `prefers-reduced-motion` by reducing scrolling animations and visual state shifts to instant transitions.
